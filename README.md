# jiangdaoyu — Personal Homepage

This repository contains a small, responsive static personal homepage.

Intended GitHub Pages URL: https://jiangdaoyu.github.io/

## Files

- `index.html`: biography, interests and links.
- `styles.css`: responsive layout and typography.
- `favicon.svg`: site icon.
- `.nojekyll`: serve static files directly.

## Publishing

Use a public repository named `jiangdaoyu.github.io`. In Settings → Pages, choose “Deploy from a branch”, select `main` and `/ (root)`, then save.

The URL above becomes available only after GitHub Pages deployment succeeds. Check the Pages settings and the deployed site before using it in a profile or submission.

## Updating

Edit `index.html` to update the displayed name, biography and links. Add only verified affiliations, publications and contact information intended for public display.
